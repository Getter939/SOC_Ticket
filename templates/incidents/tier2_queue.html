{% comment %} Filter bar — the same one as Active Tickets / History, with this queue's two scopes kept as count pills on top. Pills, not dropdowns, for stage and claim: with three low-cardinality scopes a select cost three interactions (open → pick → submit) and, worse, hid the distribution — the stage split was unknowable without filtering three times. Each pill carries the count you would get by clicking it (within the other filters), so the breakdown reads at a glance. Claim state rather than an Emergency filter: the default sort already floats emergencies and every emergency row is tinted + badged, so an Emergency filter only restated the sort — while its "Normal only" value could hide an active emergency. Claim state is what the table cannot answer on its own. For the same reason the shared bar here has no ความฉุกเฉิน select, and no date range either: this queue is worked by time-in-stage (รอมานาน), not by วันที่แจ้ง. Selects apply on change (.js-autosubmit), the search on Enter; sort lives in the results bar above the table and in the sortable headers. {% endcomment %}
